# Full Stack Attendance Management System

A web-based application designed to simplify student attendance management through an interactive interface and a MySQL database.

## Features
- Manage student and subject records.
- Mark and maintain student attendance.
- View attendance dashboards and reports.
- Track subject-wise attendance.
- Store and retrieve data using MySQL.

## Technologies Used
- **Frontend:** HTML, CSS, EJS
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Tools:** Visual Studio Code, MySQL Workbench

## Project Structure
- `server.js` – Handles server operations and application routes.
- `db.js` – Manages database connectivity.
- `schema.sql` – Defines the database structure.
- `views/` – Contains EJS templates for application pages.
- `public/` – Stores CSS files and images.

## Setup
Install Node.js and MySQL, install dependencies using `npm install`, configure your database connection, and initialize the database using `schema.sql`. Start the application using the script defined in `package.json`.
